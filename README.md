# موقع الدفاع الجوي

هذا المشروع هو موقع ويب للدفاع الجوي مع ميزات الأمان، بما في ذلك تقييد الوصول المستند إلى عنوان IP.

## كيفية التشغيل

1.  **تثبيت Node.js:**
    تأكد من أن لديك Node.js مثبتًا على جهازك. يمكنك تنزيله من [nodejs.org](https://nodejs.org/).

2.  **تنزيل المشروع:**
    قم بتنزيل أو استنساخ هذا المستودع إلى جهازك.

3.  **تثبيت الاعتماديات:**
    افتح نافذة الأوامر في مجلد المشروع وقم بتشغيل الأمر التالي:
    ```
    npm install
    ```

4.  **تكوين عنوان IP الخاص بك:**
    *   ابحث عن عنوان IP العام الخاص بك عن طريق البحث في جوجل عن "what is my ip".
    *   افتح ملف `config.json`.
    *   استبدل `"YOUR_PUBLIC_IP_HERE"` بعنوان IP العام الخاص بك.
    *   مثال:
        ```json
        {
          "allowedIps": ["127.0.0.1", "::1", "8.8.8.8"]
        }
        ```

5.  **تشغيل الخادم:**
    قم بتشغيل الأمر التالي في نافذة الأوامر:
    ```
    npm start
    ```

6.  **الدخول إلى الموقع:**
    افتح متصفح الويب الخاص بك وانتقل إلى `http://localhost:3000`.
